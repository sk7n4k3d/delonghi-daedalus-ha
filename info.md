# De'Longhi My Coffee Lounge (Daedalus)

**Beta.** Monitor the appliance over the local network and with optional
read-only cloud telemetry. For older **Coffee Link** machines, install the upstream
[`delonghi-ha`](https://github.com/sk7n4k3d/delonghi-ha) instead.

For the **Eletta Ultra**, **PrimaDonna Aromatic** and other machines on the
**My Coffee Lounge** app (package `com.delonghigroup.daedalus`).

Sign in, select your machine and approve its LAN certificate on a network you
trust. After upgrading from 0.4.7, open **Reconfigure** to approve the LAN
certificate for an existing entry. [Setup guide](https://github.com/sk7n4k3d/delonghi-ha/blob/master/docs/daedalus-setup.md)

Source of truth: [`delonghi-ha`](https://github.com/sk7n4k3d/delonghi-ha)
upstream. This repo is a HACS packaging mirror.
